我们是总部位于香港的 IVAN 集团在巴西的运营公司，为印制电路板制造与电子组装产业提供机器、设备及材料，连接中国供应链与巴西及南美市场。

集团总部位于香港，公司依法设立于巴西

IVAN INTERNATIONAL TRADER GROUP LTDA 是 IVAN 集团（总部位于香港）在巴西依法设立的公司。

依托中国供应链与集团的技术资源，我们致力于开拓巴西及南美市场，为电子电路板制造与组装产业提供机器、设备及材料。

我们的服务模式融合国际供应、专业技术与本地支持，深入了解客户的生产需求，提供符合实际情况的解决方案。

钻针研磨机发展历程

集团主营设备从研发到进入南美市场的历程。

  1. 2006–2012

    投入研发全自动钻针研磨机。

  2. 2012

    产品成功投入市场销售应用。

  3. 2012–2026

    设备销往亚洲、欧洲及美洲等多个市场的 PCB 制造企业。

  4. 2026

    开始为南美客户提供 PTH 水平沉铜线服务。
